# Wecon VD3E: сверка драйвера с документацией производителя

Сверка драйвера `wecon` (ветка `synctwin/v1.46`) с документацией Wecon. Код драйвера здесь не меняется — только
факты и предложения.

**Источники:**
- руководство пользователя «VD3E Series Bus Type Servo Drive User Manual» V3.2 (февраль 2025);
- таблица кодов аварий «VD3E 1.15» (xlsx, для прошивки V1.15);
- чертёж двигателя WD80M-07530D.

Страницы указаны по печатной нумерации руководства. Номер страницы в PDF = печатный + 9.

**Сверялись:**
- `src/devices/lcec_wecon.c`;
- `documentation/wecon.md`;
- общий класс `src/devices/lcec_class_cia402.c` / `.h` / `_opt.h`.

**Статусы:**
- **совпадает** — драйвер и документация согласуются;
- **нет** — в драйвере нет того, что описано в документации (или наоборот);
- **расходится** — драйвер или `wecon.md` утверждают иное, чем документация.

## Предложения правок (код не менялся)

### Высокий приоритет

1. **`wecon.md:67`** — исправить утверждение «температура не доступна». Температура IGBT есть в U0-32 = 0x201E:0x20 (°C), температура в момент аварии — в 0x201F:0x06. Масштаб нужно проверить на стенде, как это уже сделано для U0-31.
2. **Быстрый останов (п. 20).** Варианты:
   - в `lcec_wecon.c` по умолчанию записывать 0x6085 разумной величиной (как сейчас делается для DC);
   - либо в `wecon.md` явно требовать `<modParam name="quickDecel" …>`;
   - либо ставить `quickStopOptionCode = 1`, тогда останов идёт по 0x6084 (умолчание 13107200 ед./с²).

   Если ничего не задать, quick stop с умолчаниями фактически не тормозит.

### Средний приоритет

3. **Источник сдвига SYNC0 (п. 7).** В комментариях `lcec_wecon.c:34-37, 88-91` и в `wecon.md:94-99` ссылаться на xlsx-таблицу кодов V1.15 и на замер на стенде, а не на «vendor manual». В руководстве V3.2 такой рекомендации нет.
4. **Цикл шины (п. 8).** Переписать `wecon.md:57-58`: минимум 125 мкс, период должен быть кратен 125 или 250 мкс (иначе Er.13); 1 мс — проверенное значение, а не требование производителя.
5. **Неприменимые modParams (п. 24).** Перечислить в `wecon.md` modParams класса, которые на VD3E не работают (`positionLimitMin/Max`, `maxMotorSpeed`, `connectionOptionCode`, `positioningOptionCode`, `encoderRatio`, `feedRatio`, `eGearRatio`). Для редуктора указать `gearRatio` → 0x6091.
6. **Допуск потерь PDO (п. 25).** Описать P00-32 = 0x2000:0x20 как средство при пропусках кадров (Er.09 / E.101). Вопрос, стоит ли драйверу писать его по умолчанию, — открытый: см. лимит записей A-91, п. 31.
7. **Цифровые входы (п. 23).** Предложить включение `enable_digital_input` (0x60FD): в TxPDO свободно 3 слота из 10. Это даёт POT/NOT/HOME и DI1…DI6 в HAL без SDO.

### Низкий приоритет

8. **`wecon.md:59-63`.** Разрядность энкодера 17 или 23 бит в зависимости от двигателя; не хардкодить 2^23.
9. **`wecon.md:49-56`.** Упомянуть, что допустимы 0x1701–0x1705 и 0x1B01–0x1B04, и что маппинг не хранится в EEPROM.
10. **`wecon.md:83-88`.** Добавить, что руководство заявляет отсутствие SDO Info и EMCY. Стенд показывает, что SDO Info работает; EMCY не ожидать.
11. **`wecon.md:78-82`.** Добавить U2-04 / U2-12 (0x2020:04 / 0x2020:0C) — версии прошивки и XML.
12. **Подсказки по пусконаладке.** Добавить в `wecon.md`:
    - CN5 — вход, CN6 — выход;
    - по умолчанию DI3 = POT, DI4 = NOT;
    - BRK-OFF (функция DO 141) нужно назначить вручную;
    - STO нет;
    - лимит записей параметров A-91;
    - лимиты момента 0x6072/0x60E0/0x60E1 работают только при P01-14 = 2.
13. **0x60B2 (п. 28).** При будущем включении torque offset проверить длину 0x60B2 по ESI: в руководстве 32 бит, в CiA 402 — 16.
